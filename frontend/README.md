# SIRILO - Frontend

Este diretório contém a interface web (Apresentação) do sistema **SIRILO (Sistema Interativo de Reunião e Integração Local)**.

## 🛠️ Tecnologias Utilizadas
* **React.js (v19)** (inicializado com Vite)
* **React Router Dom** para roteamento SPA (Single Page Application)
* **Axios** para requisições HTTP
* **Vanilla CSS** com variáveis globais para a estilização
